# 将棋けいこ帳

1日30分、四間飛車で将棋ウォーズ初段を目指すための自分用の練習アプリ。

- 公開URL: https://hollowmark-dev.github.io/shogi-keiko/
- 記録は端末のブラウザ（localStorage）にだけ保存する

## 今できること

- **詰将棋ドリル**（1手詰400問・3手詰400問）
  - 間隔反復: 正解するたびに 1日→3日→1週間→2週間→1か月→2か月 後に再出題。間違えると翌日に戻る
  - 1手詰を40問解いて正答率80%以上になると、3手詰が混ざり始める（設定で前倒しできる）
  - 不正解のときは、相手の逃げ方を盤上で見せる
  - 詰んだあと、玉のまわりの各マスについて「なぜ逃げられないか」を表示する
- **四間飛車の定跡ドリル**（後手四間飛車・5章13本）
  - 章: 基本の駒組み／対▲4五歩早仕掛け／対棒銀／対▲5七銀左急戦（山田定跡・鷺宮定跡）／対居飛車穴熊
  - 新しい手順は「見る」で解説つきで並べてから練習する。練習ではアプリが居飛車側を指し、自分は四間飛車側を指す
  - 駒組みの共通部分は自動で進め、分かれ目の少し前から指す
  - 間違えると正しいマスが光る。別の手順にある手なら「それも定跡」と知らせる
  - 手順1本を1問として、詰将棋と同じ間隔反復で復習する。新しい手順は1日1本まで
- **今日のメニュー**（詰将棋10分・定跡5分・対局10分・振り返り5分）のチェックと連続日数
- **学習の段階表示**（使い始めた日から数えて第1〜第3段階）

## 問題について

問題は市販の本やサイトからは取らず、`scripts/generate.mjs` で自動生成した。採用条件は次のとおり。

- 指定の手数より短い詰みがなく、初手が1通りしかない
- 攻め方の駒は、どれを抜いても詰まなくなる（飾りの駒がない）
- 3手詰は、本手順で持ち駒が余らない
- 無駄合も合法手として扱う厳密な判定で詰む（詰将棋独特の約束を知らなくても解ける）

```bash
npm run generate   # 既定は 1手詰400・3手詰400・seed 20261004（同じ seed なら同じ問題になる）
```

## 定跡データについて

原稿は `content/joseki.json`（日本語の棋譜）。Webの定跡解説（Wikipedia・将棋の定跡サイト・個人の講座記事）で手順を集め、`npm run build-joseki` で1手ずつ合法手として検証して `docs/data/joseki.json` を作る。

- 手順を2つ以上の出典で確認できたものは「確認済み」、1つだけのものは「出典1つ」としてアプリに表示している。各手順の `memo` に、どの手をどの出典で確認したかを書いてある
- 解説文は出典の文章を写さず、要約して書いている
- 対居飛車穴熊の章はすべて「出典1つ」。△7三桂速攻の分岐は、出典の筆者自身が終盤を都合のよい手順と注記している

## 開発

```bash
npm test        # ルール判定（perft）・全問の手順再生・棋譜表記のテスト
npm run serve   # http://localhost:8766/
npm run build-joseki  # content/joseki.json → docs/data/joseki.json
```

ビルド手順はなく、`docs/` をそのまま GitHub Pages で配信している。

| パス | 内容 |
|---|---|
| `docs/js/engine/shogi.js` | 盤面・SFEN・合法手（二歩・打ち歩詰め・行き所のない駒を含む） |
| `docs/js/engine/mate.js` | 詰み探索・アプリ側の応手選択 |
| `docs/js/engine/notation.js` | 棋譜表記（▲２二金打・同・成/不成・右左上引寄直） |
| `docs/js/game/srs.js` | 間隔反復と1日の出題の組み立て |
| `docs/js/game/plan.js` | 学習の段階と毎日のメニュー |
| `docs/js/ui/` | 画面 |
